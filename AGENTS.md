Read this first; it should be enough context for most tasks. Only open [docs/SPEC.md](docs/SPEC.md) when a change affects requirements, URLs or design rules.

## What this is
The personal blog of Chittapriya Mondal, at https://www.chittapriyamondal.com. It is a static **Astro 7** site with TypeScript, no UI framework and no Tailwind, deployed to **GitHub Pages**: GitHub Actions builds the site and pushes `dist/` to the `gh-pages` branch. Runtime dependencies: `astro` and `photoswipe` (image zoom). Nothing else.

## Commands
- `npm run dev`: dev server on :4321
- `npm test`: `astro check` + `astro build`. **Run this after every change; it must pass.** CI runs the same.
- `npm run preview`: serve `dist/`
- `npm run new-post -- <slug> "<Title>"`: scaffold a draft post

## Conventions
- **Posts:** one folder per post, `src/content/blog/<kebab-slug>/index.md`, with images in `./assets/`. Use relative Markdown image paths (`![alt](./assets/x.png)`), never absolute `/…` paths or raw `<img>`, so Astro can optimise them and the zoom viewer picks them up. The slug becomes the URL: `/insights/<slug>/` (the content folder is still called `blog` internally).
- **Post body** starts at `##`. The layout renders the title as the H1 from front matter.
- **Required front matter:** `title`, `date`, `description`, `cover`. For diagrams or screenshots used as covers, set `coverFit: contain`. `draft: true` hides a post.
- **Diagrams:** keep the `.drawio` source next to the exported `.png` in `assets/`.
- **Styling:** use the CSS custom properties in `global.css` (`--primary`, `--surface`, `--text-muted`, …). Never hard-code colors in components. The site is **light theme only, in blue tones**; there is no dark mode, so don't add one unless asked. Styles are component-scoped `<style>` blocks.
- **Layout** must work at 390px wide with no horizontal scroll.
- **URLs** use trailing slashes (`trailingSlash: 'always'`). Don't change an existing post's slug; if you must, add a redirect in `astro.config.mjs`.
- Keep dependencies minimal. Ask before adding a framework (React, Tailwind, etc.).
- Don't commit `dist/`, `.astro/` or `node_modules/` (all gitignored).

## Gotchas
- `src/content/blog/*/index.md` is the only glob loaded. Other files in post folders (e.g. `.drawio`) are ignored by the build.
- On the post page, the cover isn't shown at the top if the same image file already appears in the post body. This avoids showing it twice.
- Redirect pages are generated by Astro `redirects` in `astro.config.mjs`: old MkDocs URLs (`/blog/YYYY/MM/DD/slug/`) and the former `/blog/` and `/blog/<slug>/` addresses all point to `/insights/…`. Never reuse `/blog/…` for anything else.
- `public/CNAME` and `public/.nojekyll` must stay. Without them the custom domain breaks, or GitHub drops the `_astro/` asset folder.
